# Таблица баланса

| Конфиг | Основные значения |
|---|---|
| combat.json | Базовая скорость 0.5; ×2 возвращает исходный темп; XP ×0.8 при ×2 |
| xp_curve.json | Максимум 100; первое прохождение 100%; повтор 50%; авто-бой 50%; 250 этапов ≈ 60 уровень |
| map.json | 250 этапов; 3/5/7 мобов; соло-босс каждый 10-й; элита 12%; чекпоинты 50/100/150/200/250 |
| death.json | −30% XP текущего забега; 30% шанс потери вещи текущего забега |
| healing.json | 1 банка на моба; стек 25; хил +50% HP и штраф XP −20% на 50 уровней |
| drop_tables.json | Эпик с элиты 15%; легендарный босс 5% + pity 5 боссов; богоподобный 5% в героике |
| equipment.json | Долото 2%; камни 5% с 100-го; заточка 10% с 30-го; максимум +20 |
| economy.json | Старт 300 серебра, 3 зелья, премиум 24ч; банк комиссия 10%; дневной лимит 50% |
| classes.json | 7 классов, 3 ветки, базовые умения, пассивки, 210 талантов, 21 сет и уникальные предметы |
| skill_effects.json | Общие шаблоны ударов, AoE, DoT, лечения, баффов, контроля, защиты и парирования |

Умения: 420 отдельных файлов в `configs/skills/<class>/<branch>/skill-NN.json`. `catalog.json` — индекс для интерфейса, `manifest.json` — индекс классов, веток и уровней. Все значения баланса новых систем берутся из `configs/balance/`.
