# Аудит исходной версии

База: `4595e59f8cd5ee96affe3f0e3494f8b247bb9eb6` в `feat/seven-classes-equipment-economy`. Проект — статическое браузерное приложение с localStorage, без серверной БД, аккаунтного API или провайдера платежей.

| Область | Было | Стало в rework v2 |
|---|---|---|
| Резервная копия | Рабочая ветка и старый main | Созданы `legacy-pre-rework` и `feature/rework-v2` от актуального HEAD; Git tag не поддержан доступным коннектором |
| Баланс | Значения в JS | Отдельные JSON-конфиги в `configs/balance/` |
| Умения | 10 имен на ветку в JS | 420 самостоятельных JSON-файлов (7 × 3 × 20) плюс индекс и манифест |
| Классы | 7 классов в expansion, ограниченный набор веточных описаний | 7 классов, 21 специализация, 28 базовых активных навыков, 14 пассивок, 210 талантов, 21 сет, уникальные предметы |
| Карта | 250 клеток, случайный гаунтлет 3–7, босс в конце | Настроенная последовательность 3/5/7, отдельный босс каждый 10-й уровень, элита 12%, шесть механик |
| Бой | Скорость/урон встроены в legacy JS, ×2 без ограничений | Вынесены скорость 0.5, ×2/XP коэффициенты, статы врагов и тайминги; новый UI/runtime использует эти значения |
| Лечение | Бесплатный привал и 3 жизни | Банка на противника; хил за опыт на чекпоинтах; одно поражение завершает забег |
| Смерть и авто-бой | Штраф от общего опыта; авто-боя нет | Потеря 30% опыта текущего забега, защита экипировки/босс-лута, авто-бой до highest−10 с 50% XP и остановкой на боссах/элитках |
| Улучшения | Несколько механик в расширении | JSON-конфиги долота, камней, заточки, свечения и героического зачарования; runtime API |
| Экономика | Клиентские данные персонажа | Серебро/прогресс персонажа отделены от алмазов/премиума аккаунта в модели runtime; локальный банк серебра |
| UI | Старые экраны выбора/карты/арены | Новый интерфейс выбора персонажа, карта, профиль, магазин, бой и экран подтверждения смерти |

## Границы текущей реализации

Данные аккаунта, сохранения и магазин работают локально в браузере. Без backend нельзя безопасно выполнять межустройственную синхронизацию, общие онлайновые рейтинги, подтверждение оплаты, начисление алмазов и античит. Дейлики/рейтинги имеют локальную основу и требуют серверного расписания/хранилища для настоящего онлайна.
