## Как распределять после просмотра

- **Персонажи** → `assets/characters/heroes/` или `assets/characters/enemies/` только после точного сопоставления.
- **Боссы** → `assets/characters/bosses/`.
- **Иллюстрации экранов** → отдельная папка `assets/ui/sections/` с осмысленными именами.
- **Иконки предметов / навыков / синергий** → соответствующие каталоги, не смешивать с фонами.
- Если назначение неясно или изображение дублирует существующее — оставить в этой папке.
